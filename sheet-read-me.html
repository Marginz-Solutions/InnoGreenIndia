PurposeBlock-wise IGIM reference for Krishnagiri covering blocks, representative villages, crop patterns, generalized soil properties, and input/dealer scoring.
Important caveatSand:Silt:Clay ratios, pH, OC, CEC and deficiency fields are block-level dominant-soil estimates, not plot-level lab values. Use soil testing before prescription.
Best useTerritory planning, horticulture targeting, crop-input stocking, micronutrient planning, drip/fertigation opportunity mapping.
SourcesOfficial Krishnagiri block/village list; TNAU Krishnagiri district plan; Krishnagiri horticulture page; district export action plan; district soil fertility publication.
New in this version
This workbook now includes a true village cluster map for Krishnagiri using six practical production-system clusters: Urban_Horticulture_Belt, Flower_Vegetable_Intensive_Belt, Highland_Horticulture_Belt, Mango_Orchard_Belt, Mixed_Dryland_Belt, and Irrigated_Valley_Mixed_Belt.
Use Village_Cluster_Map for village targeting, Cluster_Opportunity for portfolio planning, and Cluster_Map_View for block-level planning summary.
